# Loot Flexer

## Overview
Screenshots your big drops and shares them to your Discord channel to flex on your friends!

## Features
- Automatically detects valuable loot drops during gameplay
- Captures and formats screenshots of your drops
- Sends real-time notifications to a designated Discord channel via webhook
- Configurable value thresholds to filter out low-tier loot

## Configuration
Access the plugin settings in RuneLite to customize the following options:
- **Discord Webhook URL:** The webhook URL where drop notifications will be posted.
- **Minimum Value (GP):** Only trigger notifications for items with a Grand Exchange price above this threshold. Defaults to 1,000,000 GP.

## Installation & Setup
1. Install the plugin through the RuneLite Plugin Hub.
2. Open the plugin settings and paste your Discord webhook URL.
3. Adjust the minimum value threshold if desired.
4. Enable the plugin and start looting!
